FAQ

Common questions about dockerpatch. See docs.html for full API/architecture reference.

Does this replace Docker?

No. It wraps your existing docker binary. Every subcommand except install is passed straight through to the real binary unmodified, regardless of your installed Docker version.

Is it safe to run an install script without reviewing it first?

docker install <name> fetches and runs a published docker run command over HTTPS. If you want to review it first, fetch /scripts/<name>.txt yourself before running.

A script is asking me to type a password/token — is that normal?

Yes. Scripts that need a real credential (a database password, an API key, etc.) prompt for it interactively at install time rather than shipping a hardcoded placeholder value in the script text. Nothing is sent anywhere except straight into the docker run command as an environment variable.

Why does the server URL keep changing?

The hosted catalog server runs behind a Cloudflare quick tunnel, which issues a new hostname on every restart. tunnel-url.txt at the repo root always reflects the current one — clients fetch it at request time instead of hardcoding a URL.

Can I run my own catalog server instead of the hosted one?

The server component isn't published in this repository (kept private, not meant to be run by third parties as-is). If you want a self-hosted catalog, you'd need to write your own server implementing the same three endpoints documented in docs.html: /api/list, /api/info/<name>, and /scripts/<name>.txt.

How does submit.html decide what's junk?

New packages (both from the automated GitHub-search discovery process and manual submissions) are filtered for: non-Latin-script or placeholder-style descriptions, generic scaffold/coursework names, image tokens that aren't real pullable images, and names over 20 characters. None of this is perfect — it's a heuristic filter, not manual curation.

I got unsupported protocol scheme "" — what does that mean?

Your cached tunnel URL is stale. Re-run the install one-liner to refetch tunnel-url.txt.

I got package not found.

Either the name has a typo, or the package was renamed/removed since you last checked. Run docker install with no arguments to see the current list.

submit.html is stuck on "Searching GitHub..."

GitHub's unauthenticated code-search API is limited to 10 requests/minute. Wait a minute and try again.

How do I remove the patch?

Delete the wrapper binary and rename docker-real back to docker. See docs.html for the exact paths.
